# Круги — ежедневка на двоих

Приложение для Андрея и Дианы: круги дел и привычек, неделя с галочками,
покупки карточками, обещания-награды, совместные планы, уровни и значки.
У каждого свой телефон и свой клиент; общее видно обоим, личное шифруется.

---

## 1. Что внутри

| Вкладка | Что там |
|---|---|
| **Круги** | Главный экран. Кольца кругов на выбранный день, серия, уровень, и 16 виджетов, которые включаются, выключаются и переставляются под себя. |
| **Неделя** | Сетка галочек: дела строками, дни столбцами. Группировка по кругам, людям или сплошняком, фильтры, подсветка, сводка. |
| **План** | План на день: дела, совместные планы (прогулка, свидание, поездка) и просьбы друг другу. Внизу — печать дня. |
| **Вместе** | Пара целиком: входящие просьбы и приглашения, обещания с прогрессом, цель недели, общие круги, лента и поддержка. |
| **Покупки** | Карточки со ссылкой, фото, ценой, магазином, для кого и к какому поводу. Доски, поводы (дни рождения), сюрпризы. |
| **Ещё** | Статистика, достижения, настройки, синхронизация, справка. |

**Круг** — это папка дел, счётчик с целью (шаги, вода, «5 задач по работе»),
список покупок или настроение. Счётчик считает за день или за неделю
(«три прогулки в неделю»).

**Видимость у каждого круга:**

* 🔒 **только я** — шифруется; пара не видит ни круга, ни дел, ни отметок;
* 👀 **видно паре** — видит кольцо и дела, может поддержать, но не правит;
* 🤝 **общий** — оба добавляют и закрывают, у дела видно, кто делает.

**Обещания.** «Закроешь „Шаги“ пять дней до воскресенья — дарю кроссовки».
Прогресс считается сам по кругам того, кому обещано. Можно и наоборот —
предложить: «если я… — подаришь…?». Наградой цепляется карточка из «Покупок».

**Опыт и значки.** +10 за дело, +10 за цель счётчика, +25 за полный день,
+30 за недельную цель, +15 за состоявшийся план, +50 за выигранное обещание,
+2 за поддержку от пары. Двадцать значков.

## 2. Публикация на GitHub Pages (один раз)

### 2.1 Репозиторий приложения (публичный)

Через **GitHub Desktop** (он уже стоит):

1. File → Add Local Repository → выбрать `C:\Users\Andrew\Documents\CLODE\Krugi`.
2. Publish repository → имя `krugi`, галочку «Keep this code private» **снять**
   (на бесплатном тарифе Pages работает только с публичным репозиторием).
3. На github.com в репозитории: **Settings → Pages → Source: Deploy from a branch**,
   ветка `main`, папка `/ (root)` → Save.
4. Через минуту адрес: `https://<логин>.github.io/krugi/`

В этом репозитории лежит только код. Никаких личных данных и токенов.

### 2.2 Репозиторий данных (приватный)

Уже создан: `krugi-data`, **Private**. Там будут `data/andrey.json` и
`data/diana.json`.

### 2.3 Токен — один раз, на компьютере

1. В приложении: **Ещё → Синхронизация → «Создать токен на GitHub ↗»**.
2. На открывшейся странице:
   * **Only select repositories** → `krugi-data`;
   * **Add permissions → Contents → Read and write**;
   * внизу **Generate token**.
3. Скопировать показанный токен, вставить в поле **Токен** в приложении и
   нажать **«Подключить»**. Владелец и репозиторий подставляются сами.

Токен — это пароль. Он хранится только в браузере устройства, в репозиторий
и в код не попадает.

### 2.4 Остальные устройства — по QR-коду

В том же экране две кнопки:

* **«Для Дианы»** — код даёт доступ к базе, но **без** ключа личного: на её
  устройстве создастся свой;
* **«Для моего устройства»** — код несёт ещё и ключ, иначе личное на втором
  своём телефоне, планшете или компьютере не откроется.

Наводишь камеру нового устройства на код → открывается приложение → одно
нажатие «Это телефон: …» → готово. Рядом та же ссылка: её можно переслать, но
открывать надо **в обычном браузере** (Safari, Chrome), а не внутри
мессенджера — иначе приложение останется жить во встроенном браузере и на
домашний экран его не поставить.

Ссылка и код — это как пароль: после подключения сообщение лучше удалить.
Из адреса устройства секрет стирается сам.

Дальше на каждом устройстве: меню браузера → **«Добавить на главный экран»**
(Android) или «Поделиться» → **«На экран Домой»** (iPhone).

## 3. Как хранятся данные

```
krugi-data/                 (приватный репозиторий)
  data/andrey.json          пишет только телефон Андрея
  data/diana.json           пишет только телефон Дианы
```

Каждый файл — это `{ profile, pub, sec }`:

* `pub` — то, что видит пара: общие и «видно паре» круги, дела, отметки,
  покупки, планы, обещания, ответы и сводка по дням (только числа);
* `sec` — всё личное, зашифрованное AES-GCM ключом, которого у пары нет.

Каждый пишет только в свой файл — значит, два телефона физически не могут
перетереть друг друга. Общие вещи (общий круг, общее дело, совместный план)
правят оба: правка чужого — это копия в своём файле с более свежим временем,
а при чтении берётся самая свежая версия. Удаление — такая же запись с
пометкой. Поэтому ничего не теряется, даже если оба правили офлайн.

Токен и ключ живут только в браузере телефона (localStorage) и в репозиторий
не попадают. Без синхронизации приложение работает целиком локально.

## 4. Посмотреть на компьютере

Двойной клик по `Открыть.bat` — поднимется локальный сервер и откроется
браузер. Просто открыть `index.html` файлом нельзя: браузер не разрешает
модулям работать с `file://`.

Полезное для проверки: `?who=andrey` или `?who=diana` в адресе выбирает
профиль сразу.
