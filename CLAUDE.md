# Круги — как устроено внутри

Приложение семейное: Андрей и Диана. Статический сайт на GitHub Pages, без
сборки и без сервера. Модули ES, загружаются как есть.

## 1. Карта файлов

| Файл | За что отвечает |
|---|---|
| `index.html` | Оболочка: шапка, нижняя навигация, шторка, всплывашка, холст конфетти |
| `css/app.css` | Все стили. Цвета только токенами — тёмная тема переопределяет их одним блоком |
| `js/util.js` | Даты (день переключается в 04:00), числа, склонения имён, экранирование, безопасные ссылки |
| `js/store.js` | Состояние `S`, сохранение в localStorage, миграция из прототипа, изменения (`put`, `setMark`, `setCount`, `setMap`, `changed`) |
| `js/model.js` | **Мир `W`**: сведение своих и чужих данных, прогресс кругов, день, серия, опыт, уровни, значки, обещания, лента |
| `js/sync.js` | GitHub Contents API: свой файл пишем, чужой читаем; разделение на `pub` и шифрованный `sec` |
| `js/crypto.js` | AES-GCM: ключ личного, шифрование и расшифровка |
| `js/ctx.js` | Текущий `W` и навигация `nav` — общие для экранов |
| `js/ui.js` | Кольца, шторка, всплывашка, конфетти, чипы, переключатели |
| `js/parts.js` | Разметка, нужная нескольким экранам: клетка круга, строка дела, карточка покупки, строка плана |
| `js/v_*.js` | Экраны: main (виджеты), week, plan, pair, wish, more |
| `js/sheets.js` | Шторки-формы: круг, дело, настройка круга, обещание, план, карточка, даты |
| `js/actions.js` | Таблица `data-a` → обработчик. Все изменения идут только через store |
| `js/qr.js` | Свой генератор QR (байтовый режим, уровень L, версии 1–20) для привязки устройств |
| `js/app.js` | Запуск, перерисовка, делегирование событий |

## 2. Правила, которые легко нарушить

**Весь текст человека выводится только через `esc`.** Тексты приходят и от
пары — без экранирования чужая карточка покупки может выполнить код в чужом
браузере. Ссылки — только через `safeUrl` (http/https), иначе `javascript:`
в ссылке товара становится дырой.

**Производное не хранится, а считается.** Серия, опыт, уровень, значки,
прогресс обещаний — всё из фактов (`summarize`, `pledgeProg`). В прототипе
серия была счётчиком, который только рос и никогда не сбрасывался.

**Каждый пишет только в свой файл.** Правка общей чужой вещи — копия в своём
файле с более свежим `upd`; при чтении LWW по `id`. Удаление — `del: 1`.
Отметки и счётчики — LWW по `at` на пару (id, день).

**Личное не должно уходить открытым.** `buildFile` делит данные: всё с
`vis: 'prv'`, `prv`, `sur` и содержимое личных кругов идёт в `sec` и
шифруется. Если вещь когда-то была публичной (`pubd`), в `pub` остаётся
пустая заглушка `stub` с новым временем — иначе у пары навсегда осталась бы
старая открытая копия. Если ключа на устройстве нет, чужой `sec` переносится
в новый файл как есть (`foreignSec`) — иначе личное с другого своего телефона
затрётся.

**Имена склоняются.** `W.gen/dat/acc` — «от Дианы», «Диане», «попросить Диану».
Глаголы прошедшего времени — через `W.say(id, 'закрыл', 'закрыла')`.

**Перерисовка не должна съедать набранный текст.** `render()` откладывается,
пока человек печатает в поле (`typing()`), и доигрывается на `focusout`.
Ползунок счётчика пишет значение без перерисовки шторки — иначе он
пересоздаётся под пальцем.

**Шторки:** «живые» (круг, настройки вида) перерисовываются при каждом
изменении, формы — нет, чтобы не стереть набранное. Черновики форм (`CF`,
`PF`, `EF`, `WF`, `TF`, `F/E/Q` в плане) живут в модулях между перерисовками;
перед каждой перерисовкой чип-кнопки сначала считывают поля (`readCF` и т.д.).

**Имя действия уникально.** `data-a` → одна функция в `actions.js`. Однажды
цель недели и подключение GitHub поделили имя `gsave`, и кнопка цели молча
перестала работать. Проверка: `grep -oE "^A\.[a-z]+ =" actions.js | sort | uniq -d`
должно быть пусто, а все `data-a` из разметки — иметь обработчик.

**QR проверяется декодером, а не на глаз.** В `проверка/qr.test.mjs`
лежит независимый декодер: строит карту служебных модулей заново, читает
формат, снимает маску, проверяет синдромы Рида — Соломона и сверяет текст.
Плюс контрольный пример RS из стандарта. Так поймалась перепутанная пара
слагаемых в генераторном многочлене — код рисовался, но не читался ничем.

**Проверки.** `node проверка/qr.test.mjs`, `node проверка/rs.test.mjs`,
`node проверка/wpush.test.mjs` — всё без установки чего-либо (`package.json`
нужен только чтобы node считал файлы модулями). Синтаксис всех модулей:
`node --check js/*.js sw.js`.

**Версия в ссылках.** `index.html` грузит `css/app.css?v=N` и `js/app.js?v=N`.
Меняешь стили или точку входа — подними число.

**Уведомления считаются проверенными только по контрольному примеру.**
Шифрование пуша (`js/wpush.js`) сверяется с примером из RFC 8291 §5 байт в
байт (`проверка/wpush.test.mjs`): те же ключи и соль — то же тело. Плюс
обратный ход (расшифровать своё) и проверка подписи VAPID чужим ключом.
Служба доставки молча выкидывает тело, которое не сходится, поэтому «вроде
отправилось» ничего не доказывает.

**Разрешение на уведомления спрашивается первым делом в обработчике нажатия.**
В Safari на айфоне окно с вопросом показывается, только пока живо нажатие:
любой `await` до `Notification.requestPermission()` — и вопроса не будет.

**Стартовый экран не запирает.** `vStart` показывается, только если нет ни
кругов, ни файла пары (`!P`). Иначе человек, подключившийся по ссылке и не
нажавший «набор для старта», не увидел бы ни просьб, ни общих кругов.

## 3. Вид кругов

`js/faces.js` — вся геометрия: кольцо, точки, стакан, шкала плюс недельный
круг. Рисовальщики ничего не считают, доля приходит из `W.prog`. Плитка и
строка — не картинка, а другая разметка ячейки, они живут в `cellHTML`.

Вид берётся из `S.ui.face`, у круга может быть своё `c.face`. Размер,
толщина, подпись, движение и палитра — тоже `S.ui`, всё правится в одной
шторке `sheetLook` с живым образцом (`facePreview`).

Палитра — только переопределение токенов через `html[data-skin]`, разметка
о ней не знает. Движение включается классом `html[data-fx="1"]` и всегда
уважает `prefers-reduced-motion`.

**Кольцо оживает только там, где изменилось.** Перерисовка идёт целиком и
часто, поэтому `movedSince(id, p)` помнит прошлую долю и ставит класс
`grow` лишь изменившимся ячейкам — иначе всё дёргалось бы при каждом чихе.

**Новые настройки внутри наборов.** В `fixup` вложенные наборы (`wk`,
`shopF`, `stat`, `wish`) собираются ДО общего `Object.assign`: иначе
`u.wk` уже заменён сохранённым объектом, и новый переключатель никогда не
появится у того, у кого приложение стоит давно. На этом однажды потерялись
«круги недели».

## 4. Данные

```js
S = { v:3, me:'andrey'|'diana', people:{...}, prefs, ui, seen,
      data: { circles, tasks, wishes, boards, events, dates, pledges, requests,
              goals, kudos, pokes, tpls,          // списки: id, own, upd, del, vis
              log, counts, answers, rsvp, thanks, sealed, claims } }  // карты по дням
```

`W = buildWorld(S, P)` — свои данные плюс публичные данные пары. Всё, что
рисуют экраны, берётся из `W`: `W.circles`, `W.myCircles` (мои и общие),
`W.yourCircles` (её «видно паре»), `W.prog(c, k)`, `W.dayOf(person, k)`,
`W.sum()` (серия, опыт, значки), `W.insLeft(k)`.

День человека: дела, где он исполнитель (`w` = его id или `both`), плюс его
дневные счётчики и настроение. День пары берётся из её опубликованной сводки
`sum.days` — чтобы личное не влияло на то, что видно.

## 5. Уведомления

Сервера нет и не нужно: уведомление паре отправляет телефон того, кто
действует. В своём файле каждый публикует `push.subs` — по записи на
устройство: подписка службы доставки плюс ключи VAPID, которыми эту отправку
подписывают. Репозиторий приватный, читают его только двое.

* `js/wpush.js` — чистая математика: подпись ES256 (RFC 8292) и шифрование
  тела aes128gcm (RFC 8291). Без состояния приложения, поэтому проверяется
  контрольным примером.
* `js/push.js` — включение на устройстве, слияние подписок, `notifyPartner`.
* `sw.js` — показ уведомления и открытие нужного экрана по нажатию.

Выключение — не удаление записи, а пометка `off` со свежим временем: иначе
подписка вернулась бы из базы при следующей сверке.

`js/note.js` — полоска сверху: то же, что во «Входящих» и в ленте, но самое
свежее и поверх любого экрана. Своего состояния не хранит, помнит только
`S.seen.note` — до какого времени человек всё видел.
